# Как запустить

Эта папка — рабочий проект на Next.js 14 + Tailwind CSS + Framer Motion.
Я не смог установить зависимости и запустить сервер прямо в этой сессии —
у неё нет доступа к npm-репозиторию (ограничение сети песочницы), поэтому
проверить сайт вживую здесь не получилось. На вашем компьютере это
ограничение не действует, всё встанет обычным образом.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 — увидите главную страницу с анимациями.
Кейс Webimzo доступен по ссылке в списке кейсов или напрямую:
http://localhost:3000/cases/webimzo

## Что уже готово

- Главная страница (`app/page.jsx`) — hero, таймлайн опыта, список кейсов,
  блок "Нравиться" с референсами.
- Один кейс — Webimzo (`app/cases/webimzo/page.jsx`) — с текстом,
  уже исправленным и переведённым в Figma.
- Переиспользуемые компоненты: `Nav`, `Footer`, `Reveal` (scroll-анимации),
  `ArrowLink` (анимация стрелки при ховере), `CaseList`, `CaseMeta`,
  `CaseSection`, `HeroCTA`, `PlaceholderBlock`.
